結論: Beta 3 は大きく分けて、Scripting API に AI / Studio 関連機能が追加され、OGraf HTML Templates の manifest と non-real-time rendering 対応が整理された更新です。既存機能の明示的な削除は確認できませんでしたが、OGraf の duration の置き場所と color pattern は新しい書き方へ移行が必要です。

Scripting API AI / Studio 系 API が追加されました。 script から Motion Deblur、IntelliSearch、Slate analysis、Speech Generation、background task の抑制などを呼び出せるようになりました。
OGraf HTML Templates duration が top-level から v_bmd.duration に移動しました。 Blackmagic Design 固有の manifest field として明確化されました。Beta 2 形式の duration を使っている template は Beta 3 形式へ更新した方が安全です。
OGraf Web Component API setActionsSchedule() と goToTime() の実装方針が強化されました。 non-real-time rendering や seek 時に、playAction、stopAction、updateAction を schedule から replay して deterministic な frame を生成しやすくなりました。
OGraf color controls color の regex pattern が lowercase only になりました。 #cc0000 のような lowercase hex を前提にした記述へ寄せる必要があります。#CC0000 のような uppercase は新しいドキュメント上では非推奨です。

Scripting API の追加

Beta 3 の Scripting/CHANGELOG.txt と Scripting/README.txt では、DaVinci Resolve 21 向けに以下が追加されています。

MediaPool / Folder / MediaPoolItem まわり

  • Folder.RemoveMotionBlur({deblurOption}) と MediaPoolItem.RemoveMotionBlur({deblurOption}) が追加され、script から Motion Deblur を実行して新しい MediaPoolItem を生成できるようになりました。
  • Folder.AnalyzeForIntellisearch(identifyFaces, isBetterMode) と MediaPoolItem.AnalyzeForIntellisearch(identifyFaces, isBetterMode) が追加され、media に対する IntelliSearch analysis を script から開始できるようになりました。
  • Folder.AnalyzeForSlate(markerColor) と MediaPoolItem.AnalyzeForSlate(markerColor) が追加され、Slate analysis の結果を指定 color の marker として扱えるようになりました。
  • ResetIntellisearchAnalysis() が Project に追加され、project 内の IntelliSearch analysis data を clear できるようになりました。

Speech Generation と background task

  • Project.GenerateSpeech({speechGenerationSettings}, timecode) が追加され、text から audio を生成し、必要に応じて timeline へ配置できるようになりました。
  • Resolve.DisableBackgroundTasksForCurrentResolveSession() が追加され、現在の Resolve session で background task を止められるようになりました。自動処理や検証時に環境を安定させたいケースで有用です。

Studio / AI 機能の前提条件が明文化

Beta 3 では Studio and AI Scripting APIs という説明が追加されました。該当 API は Free 版では失敗する場合があり、必要な Extras package が未インストールの場合も False や error status になることがあります。

実装時の注意: AnalyzeForIntellisearch、AnalyzeForSlate、extended language model を使う transcription、GenerateSpeech などは、Resolve Studio と必要な Extras の有無を前提に error handling するべきです。

OGraf HTML Templates の変更

Manifest の duration が v_bmd.duration へ移動

Beta 2 では top-level に書いていた duration が、Beta 3 では v_bmd object の中に移動しました。

Beta 2 "duration": 5

Beta 3 "v_bmd": { "duration": 5 }

これにより、OGraf 標準の field と Blackmagic Design 固有 field の境界が明確になりました。既存 template を Beta 3 に合わせる場合、manifest の移行が最優先です。

Non-real-time rendering の実装がより堅牢に

03-Web-Component-API.md と example の Breaking-News.js / Sport-Match-Result.js では、goToTime() の実装が大きく更新されています。

  • load() で初期データを _initialData として保持するようになりました。
  • setActionsSchedule(payload) で schedule を保持し、goToTime(payload) で指定 timestamp までの action を replay する設計になりました。
  • updateAction() の変更を _initialData に同期し、seek や frame-by-frame rendering で編集済み property が巻き戻らないようになりました。
  • stopAction() は _currentStep = 0 として hidden state を表すようになりました。

利用者側の効果としては、timeline 上で scrub / render したときの表示が安定し、operator が変更した text や color が non-real-time render で失われにくくなります。

Color property の扱い

color picker 用の gddType は継続ですが、pattern は ^#[0-9a-f]{6}$ または ^#[0-9a-f]{8}$ のように lowercase only と説明されています。

Beta 2 の ^#[0-9a-fA-F]{6}$ を使っている template は、Beta 3 のサンプルに合わせて lowercase に寄せるのが無難です。

Install path の説明が修正・拡充

OGraf template の install path は、per-user と system-wide に分けて説明されるようになりました。特に Windows の per-user path は %APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Titles\... と明記されています。
